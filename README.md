# boona.in

Boopathi Thangamani's site. I build AI software and show the numbers.

- `design/` — tokens (`tokens.json` is the single source of truth), build script, Figma sync.
- `src/` — React + Tailwind + TypeScript. Pages are data-driven from `src/content/`.
- `npm run check` — tokens → build → test → verify (screenshots of every route in `verify/`).

Deployed on Vercel from `main`. See `design/README.md` and `src/components/README.md`.
